# Class worksheets that Copilot reads, in class order.
#
# To add a worksheet, paste its Google Doc share address on a new line. The
# Doc must be shared as "anyone with the link can view". Within an hour,
# scripts/update-worksheets.sh (run by GitHub Actions) downloads it, writes
# the Doc's title after the address, and links it from
# copilot-instructions.md. To remove a worksheet, delete its line.
#
# Lines that start with "#" and blank lines are skipped. Anything after the
# address on a line is the title the script wrote; you don't need to type it.
